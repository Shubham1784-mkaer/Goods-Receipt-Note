# Goods Receipt Tracker

A React + Vite Goods Receipt / RTV tracker matching the provided UI.

## Features
- Add receiving and RTV entries by date, vendor, item and supplier
- Add new vendors/items
- Local browser storage using `localStorage`
- Summary by date/vendor/item
- Excel export
- Print / PDF
- Responsive UI
- GitHub Pages compatible

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are generated in `dist/`.

## GitHub Pages

Push this project to GitHub, install dependencies, and use a GitHub Pages deployment workflow to publish `dist/`.
